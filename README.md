# タップタイマー — ソースコード

作成したタイマーのHTML・CSS・JavaScript一式です。外部ライブラリは使っていません。

## 起動方法（パソコン）

ZIPを展開して、このREADME.mdがあるフォルダで次のコマンドを実行します。
Python 3が必要です。

```sh
python3 -m http.server 8000 --directory dist
```

Windowsでpython3が使えない場合は、代わりに `py -3` または `python` を使ってください。
ブラウザで http://localhost:8000 を開くと起動します。
終了するときは、コマンドを実行した画面で Ctrl+C を押してください。

JavaScriptのモジュールを使うため、index.htmlをダブルクリックするだけでは起動できない場合があります。

## iPhoneで使う場合

公開済みのサイトを開くか、dist内の6ファイルを同じ構成のままHTTPS対応のWebサーバーに配置してください。
公開済みサイト: https://tap-time-1018.h-kagawa.chatgpt.site

最初に「音を試す」で音量を確認してください。画面を開いたまま使う設計です。
画面のロック中や別アプリの使用中には、アラームが鳴らない場合があります。
自動ロックの防止は、対応ブラウザと端末の状態により利用できます。
iPhone実機での表示・音声確認は未実施です。

## ファイルの役割

| ファイル | 内容 |
| --- | --- |
| dist/index.html | 画面と設定ダイアログ |
| dist/style.css | 配色・ボタン・iPhone向けレイアウト |
| dist/app.js | ボタン操作・設定保存・画面更新・画面維持 |
| dist/timer-core.js | 残り時間の計算・加算・リセット・初期設定 |
| dist/audio.js | アラーム音の生成と再生 |
| dist/icon.svg | サイトのアイコン |
| tests/timer.test.js | 時間計算・アラーム処理のテスト |
| package.json | テスト実行設定 |

## 動作

初期設定は10秒、加算時間は5秒です。
「スタート」で初期時間から開始します。
「加算式」の大きなボタンは残り時間に加算し、直ちにカウントダウンを続けます。
「リセット式」の大きなボタンは初期時間に戻し、直ちにカウントダウンを続けます。
一時停止中でも、補充ボタンを押すと再開します。
「停止して戻す」は初期時間に戻して停止します。

設定画面で初期時間・加算時間・音の有無・音の種類・音量・鳴らす長さ・画面維持を変更できます。
時間は1〜86,400秒の整数で指定できます。設定はそのブラウザに保存されます。
初期値をコードから変える場合は、dist/timer-core.jsのDEFAULTSを編集します。
すでにブラウザに保存した設定がある場合は、その保存済み設定が優先されます。

## テスト

Node.js（node:test対応版）がある環境で、このフォルダから実行します。
追加パッケージのインストールは不要です。

```sh
npm test
```

作成時に15件のテストが通過しています。実際のブラウザ表示や端末スピーカーの検証とは異なります。
